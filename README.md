# Greenfield Farms

Farm management and storefront application built with Vite + React + TypeScript, Tailwind CSS, and Supabase.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Supabase (database, auth, edge functions)
- Lucide React icons

## Getting started

```bash
npm install
npm run dev
```

## Project structure

- `src/` — application source (components, pages, hooks, context, types)
- `supabase/` — Supabase config, migrations, and edge functions
